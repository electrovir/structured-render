      Binds Structured Render to the given icons object (the same object you would pass to the icons render option). Returns:

      • Shapes for every data type that can contain an icon. Unlike the standalone shapes (like structuredRenderDataShape), these reject unknown icon keys at runtime and type iconKey as the icons object's keys.
      • VirStructuredRender: VirStructuredRender with icons already set. Its assign omits the icons option and requires data to only use the icons object's keys. It can't be constructed with new.
